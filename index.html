🔑 Get a Gemini API Key

To use natural language queries on your ticket data, you need a free API key from Google AI Studio:

  1. Go to Google AI Studio.
  2. Sign in with your Google Account.
  3. Click Create API Key.
  4. Copy the key string (starts with AIzaSy...).
  5. Paste it into the API key field in this app.
Privacy Note: Your API key is stored securely in your local browser storage (localStorage) and is sent directly to Google's API endpoint. It is never logged or sent to any third-party server.
